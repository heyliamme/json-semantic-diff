# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep discussion about the work. To report
unacceptable behaviour, use the repository's
[private report form](https://github.com/heyliamme/json-semantic-diff/security/advisories/new) and say it
is a conduct report. Only the maintainers see it, and reports are kept confidential.
